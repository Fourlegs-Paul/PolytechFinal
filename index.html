# 에이전트 작업 규칙

- 수정 전 현재 프로젝트를 먼저 확인한다.
- 아직 수정하지 말고 계획부터 설명한다.
- 관련 없는 파일은 변경하지 않는다.
- 실행 결과를 확인한 뒤 완료를 보고한다.
- 중요한 변경은 관련 MD 문서에 반영한다.
문서는 명령이 아니라 지속되는 기준입니다.코드가 바뀌면 문서도 갱신합니다.
